1. PROJECT OVERVIEW
-------------------
Built a complete Smart Restaurant Management SaaS Platform called "RestaurantOS"
using Next.js 16, TypeScript, Tailwind CSS, Appwrite Cloud, Zustand, Recharts, and Gemini AI.

- Live URL: https://restaurantos-gilt.vercel.app
- GitHub Repo: https://github.com/londhepratik2008-maker/restaurantos
- Database: Appwrite Cloud (Singapore Region)
- Auth: Appwrite Email/Password + Google OAuth

2. TECH STACK
--------------
- Framework: Next.js 16 (App Router, Turbopack)
- Language: TypeScript
- Styling: Tailwind CSS v4
- UI Components: Radix UI (Dialog, Tabs, Select, etc.)
- State: Zustand with persist middleware
- Forms: React Hook Form + Zod validation
- Charts: Recharts
- Backend: Appwrite Cloud (Auth, Database, Storage)
- AI: Google Gemini 2.0 Flash API
- Deployment: Vercel (auto-deploys from GitHub)
